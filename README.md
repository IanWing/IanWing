# Hi 👋 thank you for stopping by!

My name is Christian, but I usually go by Chris or Ian :) I am Frontend-focused web developer with 5+ years of professional experience building and maintaining websites and web applications.


## How I like to code
Professionally, I'm a frontend developer. But what really gets me going is building interfaces that go beyond brochure sites: dashboards, tools, anything where data actually moves and reacts, not just sits on a page.

My hobbies include: slowly turning my house into a data collection hub, powered by more ESP32 boards than I'd like to admit, mostly used to pull real-world data into things I build. **If you have time and ideas to code, I'm looking for someone to build with.**

I have a soft spot for React and modern JS frameworks in general, I'm currently deep diving into Svelte and Next.js. *Headless CMS integration is next on the list.*

Slowly recovering from a *too-many-private-repos* syndrome.
